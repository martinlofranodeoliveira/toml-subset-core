# toml-subset-core

Interpretador e serializador de subconjunto TOML v1.0: tabelas, chaves
pontilhadas, arrays, tabelas inline. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 5 testes, node:test, sem dependências
npm run demo
```

Sem datas (rejeitadas com clareza); arrays homogêneos. MIT — veja `LICENSE`.
